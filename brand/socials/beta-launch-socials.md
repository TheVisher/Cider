# Cider Beta Social Package

## Discord Server Setup

Server name: `Cider`

Short description:

> A small beta community for Cider, a native macOS app for capturing bookmarks, notes, ideas, and context without leaving what you're doing.

## Discord Categories And Channels

### Start Here

`#welcome`

Channel description:

> Start here for what Cider is, where to get the beta, and how to share feedback.

Pinned post:

> Welcome to Cider.
>
> Cider is a lightweight native macOS app that opens with a double-tap of Option and gives you a fast place to capture bookmarks, notes, dates, contacts, and ideas.
>
> This server is for beta discussion: how you use Cider, what feels good, what breaks, and what you wish it did next.
>
> Good places to start:
> - Use `#questions` if you need help.
> - Use `#bugs` if something breaks.
> - Use `#ideas` for feature requests or workflow suggestions.
> - Use `#beta-feedback` for broader impressions.
>
> Thanks for helping shape the app while it is still early.

`#announcements`

Channel description:

> Beta builds, release notes, important updates, and known launch notes.

First post:

> Cider is not publicly launched yet. Beta updates, build links, and important notes will show up here as they are ready.

`#rules`

Channel description:

> A few simple rules so the beta stays useful.

Pinned post:

> Keep it useful and kind.
>
> 1. Be respectful.
> 2. Keep feedback specific when you can.
> 3. Do not post private data, API keys, tokens, or sensitive screenshots.
> 4. Report bugs in `#bugs`.
> 5. Share ideas in `#ideas`.
> 6. No spam, self-promo, or unrelated promotion.
>
> Critical feedback is welcome. Drive-by nastiness is not.

## Reply Snippets

When someone asks what Cider is:

> Cider is a native macOS app for quickly capturing bookmarks, notes, dates, contacts, and ideas. It opens with a double-tap of Option so you can save context without leaving what you are doing.

When someone asks how it compares to Notion or Obsidian:

> I see Cider as lighter and more capture-first. Notion and Obsidian are great full systems. Cider is meant to be the fast native Mac layer for grabbing and organizing context as it appears.

When someone asks about AI:

> The AI layer is optional. Cider should be useful as a normal native capture and organization app first. AI should help with recall and synthesis later, not become the whole product.

When someone reports a bug vaguely:

> Thanks, that helps. Could you add your macOS version, Cider version, and the steps that got you there? If you can reproduce it, that makes it much easier to fix.
