Cider Dashboard Feature Map

The dashboard is personal context resurfacing + curated discovery + action routing. Desktop/vault is source of truth first; Web/mobile come after schema gates.
Signals
Vault, tastes, projects, schedules, external selected sources.
Gate
Generic/no-reason cards should stop before storage.
Storage
Desktop/vault snapshot is the MVP source of truth.
Actions
Start with seen/dismiss/rate/open; grow into Cider object creation.
