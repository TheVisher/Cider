# Todos And Reminders Roadmap

## Near-Term

- Natural-language reminder capture.
- Safer assistant mutations for todos/date cards.
- Better recurring todo support.
- Stronger notification delivery verification.
- Dashboard and text briefing views over the same life context.

## Later

- Location-aware/geofence reminders.
- Mobile surfacing.
- Durable wake jobs for provider/iMessage delivery.
- Richer follow-up reminders from bookmarks, notes, media, and projects.
