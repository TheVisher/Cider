# Cider Marketing Plan (Early)

## Positioning
- "A native macOS command palette that replaces Dock + Stage Manager."
- Focus on **instant access**, **window control**, **speed**, and **native feel**.

## Taglines
- "Double-tap. Click. Done."
- "All your windows, one keystroke away."
- "The command palette your Mac deserves."

## Teaser Video (15–30s)
**Shot list**
1) Desktop with multiple windows scattered.
2) Double-tap Option key.
3) Command palette appears (acrylic, clean).
4) Click a window → instantly focused.
5) Show pinned apps with running indicators.
6) Close palette, back to work.
7) End with logo + name.

**Tips**
- Record at 2x retina, crop to 1080p.
- Use macOS screen recording + trim in iMovie/CapCut.
- Keep cursor visible and intentional.
- Show speed — palette appears instantly.

## Reddit Launch Checklist
- Post title idea: "I built a native macOS command palette that replaces Stage Manager."
- Provide 1 GIF + 1 short paragraph (problem → solution).
- Key pain point: "Stage Manager is slow and unpredictable. Cider gives you direct control."
- Ask for feedback on activation method + multi-monitor behavior.

## Assets Needed
- Logo (amber spiral).
- 2–3 hero screenshots (command palette on different backgrounds).
- 1 short demo clip (15s showing double-tap → click → focus).
- Comparison graphic: Dock + Stage Manager + Spotlight → Cider.

## Key Messages
1. **Speed**: Appears in <100ms. No loading, no lag.
2. **Control**: You decide where windows go. No automatic grouping.
3. **Native**: Built with Swift/SwiftUI. Feels like it shipped with macOS.
4. **Simple**: Double-tap, click, done. No learning curve.

## Target Audience
- Power users frustrated with Stage Manager
- Developers who switch between many windows
- Anyone who wishes Cmd+Tab showed windows, not apps
- Raycast/Alfred users who want better window management
