# Cider Docs

Status: pointer to canonical docs.

Start with `Docs/INDEX.md`.

Cider's active docs are the core docs listed in `Docs/INDEX.md`. They describe durable second-brain product, architecture, storage, CLI, QA, design, convention, and agent rules.

Roadmap, specs, QA evidence, bugs, implementation notes, review findings, failed attempts, and completed plan history belong in Kanban. The active roadmap source is the Second-Brain Roadmap v1 board.

The pre-second-brain product line is preserved on `legacy/pre-second-brain-cider` for reference. Do not treat old docs from that branch as active instructions unless a durable fact has been intentionally promoted into the current core docs.

When old Markdown or legacy branch content is consulted:

1. Harvest durable facts into a core doc.
2. Convert active work, ideas, bugs, or QA evidence into Kanban if needed.
3. Leave historical context in git history or on the relevant Kanban card.

Do not create a permanent Markdown audit report. The cleanup Kanban card is the audit log.
