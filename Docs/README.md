# Cider Docs

Status: legacy filename kept as a pointer.

Start with `Docs/INDEX.md`.

Active Cider docs should be limited to the core docs listed in `Docs/INDEX.md`. Roadmap, QA evidence, bugs, implementation notes, review findings, failed attempts, and completed plan history belong in Kanban.

During the docs diet migration, old Markdown files should be processed one by one:

1. Harvest durable facts into a core doc.
2. Convert active work, ideas, bugs, or QA evidence into Kanban if needed.
3. Delete the old doc after harvesting.

Do not create a permanent Markdown audit report. The cleanup Kanban card is the audit log.
